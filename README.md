# 2NCN

โปรแกรม Windows สำหรับแปลงเพลงคาราโอเกะจาก EMK, SonicSound Karaoke (.smd) Handy Karaoke (.hnk) SIBSIB Karaoke (.sib) และ MIDI Karaoke (.kar) เป็นชุดไฟล์ NCN (.mid, .lyr และ .cur)

## วิธีใช้งาน

1. ดาวน์โหลด [2NCN-Windows-x64.exe](https://github.com/cushyam555/2NCN/raw/refs/heads/main/downloads/2NCN-Windows-x64.exe)
2. เปิดโปรแกรมแล้วกด **เลือกไฟล์เพลง** หรือเลือก **ชนิดไฟล์** เป็น **ทุกชนิด**, **EMK**, **SMD**, **HNK**, **SIB** หรือ **KAR** ก่อนกด **สแกนโฟลเดอร์** โปรแกรมจะค้นในโฟลเดอร์หลักและโฟลเดอร์ย่อย เปลี่ยน **ชนิดไฟล์** เพื่อกรองเพลงที่โหลดไว้ได้ทันที หากสแกนเฉพาะชนิดไว้ ให้เลือก **ทุกชนิด** แล้วสแกนอีกครั้งเพื่อโหลดไฟล์ชนิดอื่นด้วย
3. ตรวจชื่อเพลง ศิลปิน เวอร์ชัน EMK ไฟล์ต้นทาง และสถานะในตาราง
4. พิมพ์คำค้นเพื่อกรองชื่อเพลง ศิลปิน หรือเวอร์ชัน เช่น `แบกรัก แจ็ค v2` แล้วกด **ล้างคำค้น** เพื่อกลับไปดูทุกเพลง
5. ใช้ **Ctrl** หรือ **Shift** เลือกหลายเพลง แล้วกด **แปลงที่เลือก** หรือคลิกขวาเลือก **แปลงเฉพาะเพลงที่เลือก** จากนั้นเลือกโฟลเดอร์ปลายทาง

**แปลงผลค้นหา** บันทึกทุกเพลงที่แสดงในตารางลงโฟลเดอร์ปลายทางเดียว ส่วน **แปลงที่เลือก** ทำแบบเดียวกันเฉพาะรายการที่เลือก

- เว้นช่อง **รหัสเริ่มต้น** ว่างเพื่อใช้รหัสเพลงจาก EMK หรือชื่อเพลงภายในแพ็กเกจ SMD หรือ SIB หากไม่มีรหัส โปรแกรมใช้ชื่อไฟล์ต้นทาง
- ใส่รหัสเริ่มต้น เช่น `0001` หรือ `A0099` เพื่อรันเลขตามลำดับในตาราง เช่น `A0099`, `A0100`, `A0101` ชื่อไฟล์ .mid, .lyr และ .cur ของเพลงเดียวกันใช้รหัสเดียวกัน
- หากปลายทางมีไฟล์รหัสเดียวกัน โปรแกรมข้ามเพลงนั้นและแจ้งในคอลัมน์สถานะ ไฟล์ที่มีอยู่จะถูกเก็บไว้

**แปลงทั้งคลัง** แปลงทุกรายการที่สแกนมาโดยสร้างโฟลเดอร์ย่อยแยกตามเพลง

กด **Ctrl+F** เพื่อไปที่ช่องค้นหา หรือ **Ctrl+A** ขณะอยู่ในตารางเพื่อเลือกทุกเพลงที่แสดง

สแกนทั้งโฟลเดอร์ได้โดยไม่กำหนดจำนวนเพลงสูงสุดในตัวโปรแกรม
คลิกหัวคอลัมน์ **ชื่อเพลง**, **ศิลปิน**, **เวอร์ชัน / รูปแบบ**, **ไฟล์ต้นทาง** หรือ **สถานะ** เพื่อเรียงตามข้อความในคอลัมน์นั้น คลิกหัวเดิมอีกครั้งเพื่อกลับทิศทาง ใช้ตัวกรอง **สถานะ** ร่วมกับคำค้นเพื่อดูเพลงที่แปลงแล้ว เพลงที่มีปัญหา หรือเพลงที่ยังไม่ตรวจ การตรวจความสมบูรณ์จะเกิดขึ้นขณะแปลงเพลง
โปรแกรมข้ามเพลงที่ MIDI ไม่สมบูรณ์หรือข้อมูลเนื้อร้องและจังหวะไม่ครบ แล้วแปลงเพลงถัดไป กด **รายงานปัญหา** เพื่อดูพาธและสาเหตุจากการสแกนและการแปลงครั้งล่าสุด หรือกด **คัดลอกทั้งหมด** เพื่อเก็บรายละเอียด
ในหน้าต่าง **รายงานปัญหา** กด **บันทึก CSV** เพื่อส่งออกรายการพร้อมรหัสเพลง รหัสปลายทาง พาธ และสาเหตุ ไฟล์ใช้ UTF-8 สำหรับเปิดใน Excel หากรหัสมีเลขศูนย์นำหน้า ให้เลือกชนิดข้อมูลข้อความเมื่อนำเข้า CSV
เวอร์ชัน EMK มาจากค่า `VERSION` ที่บันทึกในหัวไฟล์ หากไม่มีจะแสดง “ไม่ระบุ”
ชื่อเพลงและศิลปินอ่านจากข้อมูลเพลงหรือจากหัวไฟล์เนื้อร้องเมื่อมีข้อมูล
ถ้าไม่มีชื่อเพลง โปรแกรมใช้ชื่อไฟล์แทน

รองรับ Windows 10 และ 11 รุ่น x64 และทำงานออฟไลน์แบบพกพาโดยไม่ต้องติดตั้ง Python
โปรแกรมอ่าน EMK แบบ SFDS และ XSTM และ SMD ที่สร้างจาก NCN2SMD และเก็บเนื้อร้องกับจังหวะจากไฟล์เดิมโดยตรง
เมื่อพบชื่อโฟลเดอร์ซ้ำ จะใส่เลขต่อท้ายเพื่อเก็บผลของทุกเพลง

ทดสอบตัวแปลงด้วยไฟล์ SFDS ตัวอย่าง ซึ่งรวมไฟล์ที่ใช้หัว MIDI แบบ `zxio` และ `OOn`
ไฟล์ SonicSound, Handy Karaoke และ SIBSIB Karaoke จะแสดงรูปแบบ `SMD`, `HNK` และ `SIB` ในตารางตามลำดับ
ไฟล์ KAR แบบ MIDI 0/1 ที่ใช้ PPQN จะแปลงจากเหตุการณ์ Lyrics หรือ Soft Karaoke Text ไปเป็น .lyr และ .cur โดยเก็บข้อมูล MIDI เดิมไว้ การจับจังหวะอิงเวลาแต่ละเหตุการณ์และปัดไปยังหน่วยเวลาของ NCN ตัวอักษรที่ชุดอักขระไทย Windows-874 เขียนไม่ได้จะใช้ `?`
รองรับไฟล์ SIB แบบ `SIBAES` ที่ใช้ค่ามาตรฐานของ NCN_to_SIB_Converter
ไฟล์ XSTM จะแสดง `XSTM` ต่อท้ายค่าเวอร์ชันที่บันทึกไว้ในไฟล์ ตารางอาจแสดง `2.0 (XSTM)` กับไฟล์ที่สร้างจาก EmkMan 3.1

## ตรวจคลัง NCN

เลือก **ชนิดไฟล์ → NCN** แล้วกด **สแกนโฟลเดอร์** โปรแกรมจะจับคู่ไฟล์ `.mid`, `.lyr` และ `.cur` ที่มีชื่อเดียวกันโดยไม่แยกตัวพิมพ์เล็กใหญ่ รองรับทั้งไฟล์ที่อยู่ด้วยกันและโฟลเดอร์ `MIDI` หรือ `Song` คู่กับ `Lyrics` และ `Cursor` ที่ใช้โครงสร้างโฟลเดอร์ย่อยเหมือนกัน เลือกโฟลเดอร์หลักที่ครอบคลุมทั้งสามส่วนเพื่อให้ตรวจพบไฟล์ประกอบครบ

เลือกสถานะ **มีปัญหา** เพื่อดูชุดที่ MIDI มีปัญหา ขาดไฟล์ประกอบ ขาดชื่อเพลงหรือเนื้อร้อง หรือมีไฟล์จังหวะว่าง ดูรายละเอียดเพิ่มเติมได้ที่ **รายงานปัญหา** และบันทึกเป็น CSV ได้ การสแกนนี้อ่านไฟล์อย่างเดียว

## คอมไพล์จากซอร์ส

ใช้ Go 1.24 ขึ้นไป จาก PowerShell บน Windows x64

```powershell
go build -trimpath -ldflags="-s -w -H=windowsgui" -o 2NCN-Windows-x64.exe .
```

ข้อมูลรูปแบบไฟล์อ้างอิงจาก [ข้อกำหนด EMK ของ emk-rs](https://docs.rs/crate/emk-rs/latest/source/emk-spec.md)
