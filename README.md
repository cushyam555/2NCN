# 2NCN

โปรแกรม Windows สำหรับแปลงเพลงคาราโอเกะจาก EMK เป็นชุดไฟล์ NCN (.mid, .lyr และ .cur)

## วิธีใช้งาน

1. ดาวน์โหลด [2NCN-Windows-x64.exe](https://github.com/cushyam555/2NCN/raw/refs/heads/main/downloads/2NCN-Windows-x64.exe)
2. เปิดไฟล์โปรแกรม แล้วกด **เลือกไฟล์ EMK** หรือ **สแกนโฟลเดอร์** เพื่ออ่านไฟล์ .emk ในโฟลเดอร์หลักและโฟลเดอร์ย่อย
3. ตรวจชื่อเพลง ศิลปิน เวอร์ชัน EMK ไฟล์ต้นทาง และสถานะในตาราง
4. พิมพ์คำค้นเพื่อกรองชื่อเพลง ศิลปิน หรือเวอร์ชัน เช่น `แบกรัก แจ็ค v2` แล้วกด **ล้างคำค้น** เพื่อกลับไปดูทุกเพลง
5. ใช้ **Ctrl** หรือ **Shift** เลือกหลายเพลง แล้วกด **แปลงที่เลือก** หรือคลิกขวาเลือก **แปลงเฉพาะเพลงที่เลือก** จากนั้นเลือกโฟลเดอร์ปลายทาง

**แปลงผลค้นหา** บันทึกทุกเพลงที่แสดงในตารางลงโฟลเดอร์ปลายทางเดียว ส่วน **แปลงที่เลือก** ทำแบบเดียวกันเฉพาะรายการที่เลือก

- เว้นช่อง **รหัสเริ่มต้น** ว่างเพื่อใช้รหัสเพลงจาก EMK หากไม่มีรหัส โปรแกรมใช้ชื่อไฟล์ต้นทาง
- ใส่รหัสเริ่มต้น เช่น `0001` หรือ `A0099` เพื่อรันเลขตามลำดับในตาราง เช่น `A0099`, `A0100`, `A0101` ชื่อไฟล์ .mid, .lyr และ .cur ของเพลงเดียวกันใช้รหัสเดียวกัน
- หากปลายทางมีไฟล์รหัสเดียวกัน โปรแกรมข้ามเพลงนั้นและแจ้งในคอลัมน์สถานะ ไฟล์ที่มีอยู่จะถูกเก็บไว้

**แปลงทั้งคลัง** แปลงทุกรายการที่สแกนมาโดยสร้างโฟลเดอร์ย่อยแยกตามเพลง

กด **Ctrl+F** เพื่อไปที่ช่องค้นหา หรือ **Ctrl+A** ขณะอยู่ในตารางเพื่อเลือกทุกเพลงที่แสดง

สแกนทั้งโฟลเดอร์ได้โดยไม่กำหนดจำนวนเพลงสูงสุดในตัวโปรแกรม
เวอร์ชัน EMK มาจากค่า `VERSION` ที่บันทึกในหัวไฟล์ หากไม่มีจะแสดง “ไม่ระบุ”
ชื่อเพลงและศิลปินอ่านจากข้อมูลเพลงหรือจากหัวไฟล์เนื้อร้องเมื่อมีข้อมูล
ถ้าไม่มีชื่อเพลง โปรแกรมใช้ชื่อไฟล์แทน

รองรับ Windows 10 และ 11 รุ่น x64 และทำงานออฟไลน์แบบพกพาโดยไม่ต้องติดตั้ง Python
โปรแกรมอ่าน EMK แบบ SFDS และ XSTM และเก็บเนื้อร้องกับจังหวะจากไฟล์เดิมโดยตรง
เมื่อพบชื่อโฟลเดอร์ซ้ำ จะใส่เลขต่อท้ายเพื่อเก็บผลของทุกเพลง

ทดสอบตัวแปลงด้วยไฟล์ SFDS ตัวอย่าง ซึ่งรวมไฟล์ที่ใช้หัว MIDI แบบ `zxio` และ `OOn`
ไฟล์ XSTM จะแสดง `XSTM` ต่อท้ายค่าเวอร์ชันที่บันทึกไว้ในไฟล์ ตารางอาจแสดง `2.0 (XSTM)` กับไฟล์ที่สร้างจาก EmkMan 3.1

## คอมไพล์จากซอร์ส

ใช้ Go 1.24 ขึ้นไป จาก PowerShell บน Windows x64

```powershell
go build -trimpath -ldflags="-s -w -H=windowsgui" -o 2NCN-Windows-x64.exe .
```

ข้อมูลรูปแบบไฟล์อ้างอิงจาก [ข้อกำหนด EMK ของ emk-rs](https://docs.rs/crate/emk-rs/latest/source/emk-spec.md)
